# Reproducing the numbers and figures of the two papers

This is the runbook for `sid2026/` (SESAR Innovation Days 2026) and
`trc-extension/` (Transportation Research Part C). It records what a person
with access to the analysis host needs in order to regenerate every number,
table and figure, and what an outside reader cannot regenerate and why.

## 1. What is reproducible by whom

| Layer | Source of truth | Who can rerun it |
|-------|-----------------|------------------|
| Raw data (19 months of flight-plan revisions and stay pairs) | S3 bucket, parquet per month (`data/ich_dataset/`, `data/stay_dataset/` on the host) | EUROCONTROL staff with the `S3_*` credentials; operational data, not public |
| Study numbers (every figure quoted in the prose) | `studies/2026-07-fuel-study/report/macros.tex`, generated by `code/run_10_report_assets.py`; per-analysis JSONs in `results/` | anyone with the raw data, by running the numbered stage scripts |
| Horizon experiment (journal Section 8) | `studies/2026-08-trc-horizon/` (its README) | same |
| Light tables the figures are drawn from | `studies/2026-07-fuel-study/tables/*.csv` (committed) and `studies/2026-08-trc-horizon/tables/*.csv` (committed) | anyone with the repository |
| Figures | drivers in `sid2026/` and `trc-extension/` (Section 3 below) | anyone with the repository, for all figures except the two maps and the pair figure, which read the raw parquet |
| Manuscripts | `sid2026/sid2026.tex`, `trc-extension/trc2026.tex`, `figures/*.pdf` committed | anyone; `tectonic` only |

The rule behind all of it: **no number is typed by hand and no metric is
re-derived**. If a figure in the prose cannot be traced to `macros.tex` or a
results JSON, it is wrong until proven otherwise.

## 2. Numbers

From the repository root, with the raw parquet present and
`PYTHONPATH=.:studies/2026-07-fuel-study/code`, run the numbered scripts in
`studies/2026-07-fuel-study/code/` in order (`run_00_download.py` …
`run_10_report_assets.py`). The report in `studies/2026-07-fuel-study/report/`
has a Reproducibility appendix with the exact commands and environment
variables; note the warning in that study's README about
`S3_SECRET_ACCESS_KEY` holding the raw secret. Heavy artefacts (models,
scored parquets) are mirrored to the bucket, not committed.

The horizon experiment is one script, `studies/2026-08-trc-horizon/code/run_horizon.py`;
see its README.

Both studies are heavy (hundreds of thousands of pairs, gradient-boosted
training). Observe the memory discipline in `AGENTS.md`: probe, then cap.

## 3. Figures

### 3.1 Environment

The project venv is enough: `uv sync` at the repository root, then run every
driver with `.venv/bin/python`. The drivers import only `matplotlib`,
`pandas`, `pyarrow`, `shapely`, `geopandas` (with `pyogrio`) and the
`skyrank` package itself (route geometry and the waypoint database, for the
maps); no `cartopy` or `shap` is imported. The one asset outside the venv is
the **Natural Earth 10 m** land and boundary shapefiles, which `style.py`
reads from the cartopy cache location
`~/.local/share/cartopy/shapefiles/natural_earth/` (see `LAND_SHP` and
`BORDER_SHP` in `sid2026/style.py`). On a fresh machine download them from
naturalearthdata.com into that path, or point the two constants elsewhere;
installing `cartopy` and drawing one map also populates the cache. Type is
STIXGeneral, which ships with matplotlib, so no system font is required.

### 3.2 Inputs that live outside `paper/`

| Driver | Reads |
|--------|-------|
| `sid2026/make_data_figures.py` | `studies/2026-07-fuel-study/tables/coverage_accuracy.csv`, `muac_operating_points.csv`, `fuel_concentration.csv` |
| `sid2026/make_shap_figure.py` | `studies/2026-07-fuel-study/tables/shap_importance.csv` |
| `sid2026/make_maps.py` | scored test parquet and the navigation database under the repository's `data/` (raw data, Section 1) |
| `sid2026/make_pair_figure.py` | `data/ich_dataset/ich_dataset_2026-04.parquet` (raw data) |
| `trc-extension/make_horizon_figure.py` | `studies/2026-08-trc-horizon/tables/*.csv` |
| `trc-extension/figures-src/fig_pipeline_paperbanana_chatgpt.md` | the PaperBanana agent prompts (Planner, Stylist, Visualizer, Critic) that the author runs by hand in ChatGPT to produce `fig_pipeline.png`; `fig_pipeline_chatgpt_original.png` is the untouched output |

All drivers hard-code the repository root as `/home/rdcodina/projects/skyrank`
and the staging directory as `/data/rdcodina/skyrank/_audit/paper/figures`.
Edit the `WT`, `T` and `OUT` constants at the top of each script on another
machine.

### 3.3 Order of operations — the shared-directory trap

Both papers' drivers write to the **same** staging directory, and the journal
driver `trc-extension/make_trc_figures.py` re-runs the SID generators with
journal sizes, **overwriting the SID renders**. Regenerate in this order and
never interleave:

```bash
# 1. SID figures at column width
cd paper/sid2026
python make_data_figures.py && python make_shap_figure.py && \
  python make_maps.py && python make_pair_figure.py
cp /data/rdcodina/skyrank/_audit/paper/figures/{fig_coverage,fig_shap,pair_idea}.pdf figures/

# 2. Journal figures at 390 pt text width (copies into trc-extension/figures itself)
cd ../trc-extension
python make_trc_figures.py && python make_horizon_figure.py

# 3. Pipeline diagram (shared by both papers): run the four PaperBanana prompts in
#    figures-src/fig_pipeline_paperbanana_chatgpt.md in ChatGPT, download the accepted
#    image at full size, trim its white margin (PIL getbbox against white, 8 px pad),
#    save losslessly as fig_pipeline.png into BOTH figures/ directories, and check the
#    dpi at the include widths (SID 0.85\textwidth, TRC 0.95\textwidth).
```

After **every** copy, check the MediaBox against the size the paper expects
(`style.SIZES` for the SID, `TRC_SIZES_PT` in `make_trc_figures.py` for the
journal), to within 0.5 pt:

```bash
python -c "import fitz,sys; [print(f, fitz.open(f)[0].rect) for f in sys.argv[1:]]" figures/*.pdf
```

A journal-sized figure was once installed into the conference paper this way
and only caught on that check.

### 3.4 Figure conventions that must survive regeneration

`sid2026/style.py` owns every colour and font size. Green is the chosen
route, red the abandoned one, one blue accent, grey for context; the routes
are separated by line style as well as colour, and two SHAP groups are
hatched, because the palette collapses to one grey in greyscale. Figures are
drawn at the size they print and included with no scaling. Neither of these
is a taste decision; both were reader-verified.

## 4. Manuscripts

```bash
mkdir -p "$TMPDIR/sid" "$TMPDIR/trc"
(cd paper/sid2026        && ~/.local/bin/tectonic -X compile sid2026.tex --outdir "$TMPDIR/sid")
(cd paper/trc-extension  && ~/.local/bin/tectonic -X compile trc2026.tex --outdir "$TMPDIR/trc")
```

Acceptance after every build: SID exactly 8 pages, TRC 36; no `Overfull`
lines in the log; no `??` in the PDF text; abstract of the TRC at or under
250 words with LaTeX markup stripped. The committed `sid2026.pdf` and
`trc2026.pdf` are the builds of the committed sources.

## 5. Content rules that bound any edit

- EUROCONTROL neutrality: no operator, waypoint, airspace volume or city pair
  is identified (the Amsterdam–Barcelona introduction anecdote is the sole
  authorised exception); the Disclaimer stays verbatim.
- Numbers come from `macros.tex` and the results JSONs, never from memory.
- Clarity is judged by zero-context readers, not by the writer (`/coldread`).
- Text removed for the SID page limit is kept in `% Cut for space:` comments.
